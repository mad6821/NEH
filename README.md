## Health of the Humanities in Appalachia

This repository contains code to replicate analyses for Health of the Humanities in Appalachia (published link forthcoming). 
1. **data**: Includes all economic data used in the analysis, pulled from the `get_data.R` file.
  - `analysis.csv` includes the merged and cleaned data. This is the main dataset for analysis.
2. **docs**: Includes all written reports for this project. 
3. **figures**: Includes all figures from the `data_visualization.R` file. 
4. **scripts**: Includes all R scripts for data export, cleaning, merging, and analysis.
5. **tables**: Includes all tables from the `data_visualization.R` file.
