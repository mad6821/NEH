## Scripts
1. `get_data.R`: Script to set up file directories, and pull all data into the directory. 
2. `data_cleaning.R`: Script to clean and merge all data into `analysis.csv`
3. `data_vis_10_16.R`: Script for static visualizations, such as figures, maps, and tables. 
4. `shiny_app.R`: Script with UI and server logic for shiny application.
